### 🚀 Featured Projects

- 🤖 **[FlowForge](https://github.com/Kanhaiya76618)**
  Autonomous exception-resolution system for logistics featuring a 6-stage multi-agent pipeline (Watcher → Diagnosis → Planner → Verifier → HITL → Executor) powered by OR-Tools CP-SAT optimizer and live tool calling.

- 🔒 **[RagVault](https://github.com/Kanhaiya76618)**
  Fully offline, privacy-first RAG platform for enterprise knowledge using FAISS + BM25 hybrid search, BGE cross-encoder reranking, and local Mistral Nemo 12B inference with zero external API calls. *(3rd Place — HAL Hackathon)*

- ⚔️ **[EnterpriseOps Arena (RL Fine-Tuning)](https://github.com/Kanhaiya76618)**
  Fine-tuned Qwen2.5-3B-Instruct via GRPO reinforcement learning with 4-bit QLoRA inside a custom multi-agent environment on a single T4 GPU. *(Top 2.5% of 32,000+ teams, Meta × Hugging Face PyTorch Hackathon)*

- ⚛️ **[Quantum Join Order Optimization (QAOA)](https://github.com/Kanhaiya76618)**
  Research co-author evaluating QAOA against classical query optimization (Selinger DP) on real IBM Quantum hardware (`ibm_kingston`) via Qiskit.
