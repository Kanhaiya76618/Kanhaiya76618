### 🚀 Featured Projects

- 🛡️ **[DataMind (Nexora)](https://github.com/Kanhaiya76618/DataMind)** — *1st Runner-Up @ ZeroDay Hacktoberfest 2026*
  Enterprise-grade verified AI Data Analyst over 6M+ Snowflake rows. Combines Google Gemma 4 with a 5-layer verification tower: dual-candidate AST consensus, post-execution shape checks, self-healing query repair, and cell-level number fact checking. (100% Gold benchmark accuracy, 206 automated tests passing).

- 🔒 **[RagVault](https://github.com/Kanhaiya76618)** — *3rd Place @ HAL Hackathon*
  Fully offline, privacy-first enterprise RAG platform using FAISS + BM25 hybrid search, BGE cross-encoder reranking, and local Mistral Nemo inference with zero external API calls.

- 🤖 **[FlowForge](https://github.com/Kanhaiya76618)**
  Autonomous exception-resolution system for logistics featuring a 6-stage multi-agent pipeline (Watcher → Diagnosis → Planner → Verifier → HITL → Executor) powered by OR-Tools CP-SAT optimizer and live tool calling.

- ⚛️ **[Quantum Join Order Optimization (QAOA)](https://github.com/Kanhaiya76618)**
  Research evaluating QAOA against classical query optimization (Selinger DP) on real IBM Quantum hardware (`ibm_kingston`) via Qiskit.

- ⚔️ **[EnterpriseOps Arena (RL Fine-Tuning)](https://github.com/Kanhaiya76618)**
  Fine-tuned Qwen2.5-3B-Instruct via GRPO reinforcement learning with 4-bit QLoRA inside a custom multi-agent environment on a single T4 GPU. *(Top 2.5% Meta × Hugging Face Hackathon)*
